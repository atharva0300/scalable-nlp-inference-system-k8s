# Scalable NLP Inference System using Kubernetes


# Project Description: 
1. Build an NLP inference system, where multiple NLP models are deployed as independent, containerized services.
2. Simulate varying workloads and enable horizontal scaling of model services on resource utilization.
3. Ensure the system remains responsive and stable under varying load conditions by dynamically adapting resource capacity and distributing requests efficiently.

# Uniqueness about the Project: 
Demonstrates dynamic scalability and high availability under varying workloads, while replicating the "core" architectural principles of large-scale NLP inference systems in a "simplified, resource-constrained environment".
